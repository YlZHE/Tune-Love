# 应用内下载去人声模型：设计

日期：2026-10-03。状态：待用户审阅。
调研：`.superpowers/research/2026-10-03-model-download.md`（不入库）；许可：`E:\autotune helper\docs\2026-10-02_model-weights-licensing.md`。

## 1. 目标

用户在应用里点一次、确认一次，就能拿到 StemgenRT 模型（约 36 MB），不用手动放文件；国内网络也能下载。
文件逐字节校验，任何来源（包括第三方加速）都不可能装进被篡改的文件。

## 2. 用户已确认的决定（2026-10-03）

1. 作者确认权重许可前，公开安装包也提供应用内下载，但必须写清“权重许可待作者确认”和训练数据的非商业条款，由用户同意后才下载。
2. 来源：直连作者仓库优先；失败时自动依次换第三方 GitHub 加速服务；一律按原始 SHA-256 校验。
3. 若下载是从“未找到去人声模型”进来的（用户点开关被拒），完成后自动开启去人声；在设置里主动下载的，完成后不自动开。

## 3. 来源与清单

清单只保留一份：`src-tauri/models.json`。Rust 用 `include_str!` 读取；`scripts/fetch-stemgenrt.mjs` 改为读同一文件；另加测试，断言它与 `licenses/StemgenRT-5.8.txt` 中写的地址、大小和哈希一致。

```json
{
  "id": "stemgenrt-hop128",
  "file": "stemgenrt-hop128.onnx",
  "bytes": 37529132,
  "sha256": "77164d6a581fafb2a31f53fd8ffde44c07cf618472952a4cdba14e68dda3b8b9",
  "origin": "https://github.com/sweetspotsoundsystem/stemgen-rt/raw/61df8f4aa1555ef110308d01ea92b54ace770979/model/model.onnx",
  "mirrors": ["https://ghfast.top/", "https://ghproxy.net/", "https://ghproxy.vip/"]
}
```

- **镜像的用法**：镜像是加在 `origin` 前面的前缀，即“前缀 + 原始地址”。
- **实测记录（2026-10-03）**：
  - 直连和上述三个镜像都返回 `206`，总大小 37,529,132 字节，开头字节与原文件一致；
  - `gh-proxy.com` 返回 403；
  - `gh-proxy.net` 返回的是一个网页，被 Windows Defender 判为“不需要的软件”。这两个都不收录。
- **维护**：每次发版前重新实测镜像列表，结果写进发布检查清单。
- **自定义前缀**：设置里可以填一个“下载加速前缀”，它排在所有内置镜像之前、直连之后。

## 4. 下载流程（Rust，`src-tauri/src/devocal/model.rs`）

- **依赖**：`reqwest`（`stream` + `native-tls`，即 Windows 自带的 schannel，跟随系统证书和系统代理）；`sha2`（已在依赖锁文件里）；`tauri-plugin-dialog`（用于“导入本地文件”时选文件）。
- **来源顺序**：
  1. 直连；
  2. 自定义前缀（如果填了）；
  3. 内置镜像，按列表顺序。

  每个来源最多重试 2 次。连接超时 10 s，读超时 30 s。连接失败、超时、5xx、429 时换下一个来源；返回网页（`content-type: text/html`）或大小不对时，立即弃用该来源。
- **断点续传**：数据写到 `models\stemgenrt-hop128.onnx.part`，旁边的 `.part.json` 记录来源和已写入的字节数。
  - 换来源或重启后，带 `Range` 继续下载：只有返回 `206`、且总大小一致时才追加；返回 `200` 则从头开始。
  - 由于整份文件最终要校验哈希，即使不同来源拼接出错也一定会被发现；校验失败就删除 `.part`，重新完整下载一次。
- **校验与安装**：下载时同时计算 SHA-256，完成后先比大小、再比哈希，都通过才 `sync_all` 并 `rename` 成正式文件名。
  - 正式文件名只能通过这次重命名产生，残缺的文件永远不会出现在正式文件名上。
  - 如果目标文件正被占用，就报 `install_denied`，提示先关闭去人声。
- **判定“已安装”**：文件大小一致，并且完整哈希已经算过一次、结果正确。哈希按“路径 + 修改时间 + 大小”缓存，不会每次查询都重算。
  - 当前的 `model_path` 只检查文件是否存在，要改成调用这个判定。
  - 环境变量 `TUNE_LOVE_STEMGENRT_ONNX` 指定的文件仍然优先，不校验，给开发者使用。
- **导入本地文件**：用文件对话框选择文件后，用同样的大小和哈希校验，复制到 `.part`，再重命名安装。
- **状态**：放在应用级 State，主窗口和设置窗口共用；关闭设置窗口不会中断下载。同一时间只有一个下载任务，跑在异步任务里。
  - 取消：每处理完一个分块检查一次取消标志，取消时保留 `.part`，下次可以续传。
  - 用户点“删除已下载部分”时，才清理 `.part`。
- **命令**：
  - `get_model_status()` 返回：`phase`（`missing / downloading / verifying / installed / failed`）、`receivedBytes`、`totalBytes`、`source`（`origin / custom / mirror:<host> / import / env`）、`path`、`error`（机器码）。
  - `model_command({ action: "download" | "cancel" | "import" | "delete", autoEnable?: boolean })`。
  - 两者都沿用现有的轮询方式（前端每 500 ms 查一次），不改 capabilities。

## 5. 与去人声衔接

- **自动开启**：`autoEnable: true` 时，安装成功后由后端调用与 `devocal_command("enable")` 相同的路径。这是因为 `unavailable` 状态只在下一次 `enable` 时才会清除，不会自己恢复。
- **主窗口提示**：缺少模型时，主窗口的提示改为“未找到去人声模型，请在设置中下载”，点一下就打开设置页并定位到去人声区域。

## 6. 界面（设置页 `DevocalSettings`）

- **“模型”一行**，各状态显示如下：
  - 未下载：按钮“下载模型（约 36 MB）”，旁边一行小字“许可待作者确认 · 来源与许可”。
  - 下载中：进度条、“已下载 x / 35.8 MB · 来源：直连 / 镜像 ghfast.top”、“取消”按钮。
  - 校验中：“正在校验…”。
  - 已就绪：“模型已就绪”，可以展开查看路径、大小、SHA-256，还有“删除模型”按钮。
  - 失败：中文错误说明、“重试”按钮、“从本地文件导入…”按钮。
- **确认框**（第一次下载前弹出；同意后按模型的 SHA-256 记住，同一模型不再重复询问）：
  - 模型名称与用途，以及“不随安装包发布”的说明；
  - 来源仓库和固定提交；
  - 大小与 SHA-256；
  - 许可状态：仓库代码采用 MIT，权重许可作者未单独声明、待确认；
  - 训练数据：MUSDB18-HQ（仅限教育用途）、MoisesDB（CC BY-NC-SA 4.0）；本应用免费、非商业，请自行判断使用场景；
  - 加速说明：可能经由第三方 GitHub 加速服务（列出名单）下载，它们能看到这次下载请求；文件会按原始 SHA-256 校验；
  - 写入位置；
  - 按钮：“同意并下载”、“取消”。
- **高级设置**：一个输入框“下载加速前缀（可选）”，只接受 `https://` 开头、以 `/` 结尾的前缀。
- **错误文案**：沿用调研 §4.2 的表格，再补两条：`source_html`（“加速服务返回了网页，已换下一个来源”）和 `all_sources_failed`（“所有下载来源都失败了。可设置系统代理、填写加速前缀，或从本地文件导入”）。

## 7. 不做

- 首次引导页（以后复用本设计的状态、确认框和“完成后自动开启”参数）；
- 第二个模型；
- 我们自己托管或转存权重；
- 后台静默下载；
- 安装时下载。

## 8. 测试

- **Rust**：
  - 可注入的假字节源，覆盖：哈希、大小、原子安装、`.part` 续传（206 / 200 / 总大小不一致）、换来源、返回网页的来源被弃用、取消后续传、导入、“已安装”判定与缓存、环境变量优先。
  - 清单与脚本、许可文本一致性。
  - 本地 `TcpListener` 假服务器，覆盖真实的 `reqwest` 路径和超时。
- **vitest**：状态解析、错误码文案、进度格式。
- **Playwright**（模拟后端）：
  - 确认框的内容；取消后不发出下载请求；
  - 进度、取消、失败与重试、导入；
  - 从“未找到模型”进来下载后自动开启去人声；
  - 已就绪状态；
  - 主窗口提示点击后打开设置。
  - 现有渲染设置页的测试都要补上 `get_model_status` 的默认返回。
- **真机**（需授权）：
  - 一次直连下载；
  - 强制让直连失败，确认会切换到镜像；
  - 下载中途断网再恢复，确认能续传；
  - 下载完成后，从“未找到模型”入口下载的会自动开启去人声。
