HTDemucs ft vocals (Demucs, Meta Platforms)
===========================================

Code:     https://github.com/facebookresearch/demucs (MIT)
Weights:  the htdemucs_ft vocals model, in the ONNX export published by StemSplitio on Hugging Face
          (model card states MIT). The exact repository address and file hash are pinned in the
          application's model manifest.

Changes made by Tune Love: the ONNX file has been cut to a 1 second fixed-length window and its graph
has been rewritten (the iSTFT ConvTranspose nodes are replaced by an equivalent MatMul plus Pad/Sum,
and the GLU Split nodes by Slice, so that it runs correctly on DirectML). The weight values are not
changed. The converted file is produced by scripts/models/convert.py and published by the Tune Love
project on its GitHub Releases; it is not stored in the source repository.

Training data: MUSDB18-HQ ("educational purposes only") plus 800 additional songs whose origin is not
disclosed. The weights are therefore for non-commercial use only. This application is free and
non-commercial, and the model is an optional download that the user must confirm.
