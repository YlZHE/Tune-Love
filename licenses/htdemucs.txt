HTDemucs ft vocals (Demucs, Meta Platforms)
===========================================

Code:     https://github.com/facebookresearch/demucs (MIT)
Weights:  the official Demucs htdemucs_ft vocals specialist (sub-model 3 of the htdemucs_ft bag).
Export:   ONNX export tooling demucs-onnx by StemSplit, https://github.com/StemSplit/demucs-onnx (MIT).
          StemSplitio's published full-length ONNX export of the same model, whose model card states MIT:
          https://huggingface.co/StemSplitio/htdemucs-ft-vocals-onnx
          (file htdemucs_ft_vocals.onnx, 316,446,953 bytes, SHA-256
          8c5d5e2da1f27050240bb80236673307ee3b40d4b064066d9350f4d64bfd544d, checked against the
          research copy on disk). The 1 second file Tune Love uses is re-exported from the checkpoint with
          that tooling, not cut from the file above. Exact file pinned by SHA-256 in the manifest.

Changes made by Tune Love: the model has been exported to ONNX with a 1 second fixed-length window and
its graph has been rewritten (the iSTFT ConvTranspose nodes are replaced by an equivalent MatMul plus
Pad/Sum, and the GLU Split nodes by Slice, so that it runs correctly on DirectML). The weight values are
not changed. The converted file is produced by scripts/models/convert.py and published by the Tune Love
project on its GitHub Releases; it is not stored in the source repository.

Training data: MUSDB18-HQ ("educational purposes only") plus 800 additional songs whose origin is not
disclosed. The weights are therefore for non-commercial use only. This application is free and
non-commercial, and the model is an optional download that the user must confirm.
